# Program-tugas-final-rekayasa-komputasional
Analisis sentimen ulasan restoran berbahasa Indonesia menggunakan TF-IDF + Logistic Regression, dioptimasi dengan Particle Swarm Optimization (PSO) untuk pembobotan fitur. Dilengkapi lexicon-based labeling, acceptance gate PSO, dan evaluasi Repeated Stratified K-Fold.
